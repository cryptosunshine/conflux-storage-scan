# Conflux Storage Node 直连 POC 人工测试清单

## 边界

- 仅在分支 `codex/direct-storage-node-poc` 上测试，不合入 `master`。
- 仅使用本机 `http://localhost` 页面。HTTPS/Cloudflare 页面会拦截两个明文 HTTP 节点。
- 使用 Conflux eSpace 测试网（chain ID `71`）和固定代理
  `0x3fF03285AA79027Ecc552432336FCB85eaD7199e`。
- 使用一个小型、非敏感、非空测试文件。第一轮建议小于 1 MiB。
- 存储费用必须显示为 `0 CFX`；钱包仍会显示独立的网络 Gas。
- 页面最多只能请求一次用户确认的 `submit` 交易。测试脚本和 probe 不会发交易。

## 用户确认的真实交易流程

- [ ] 执行 `corepack pnpm harness:storage-probe`，确认至少一个健康完整节点。
- [ ] 执行 `corepack pnpm dev`，打开终端显示的本地 HTTP 地址。
- [ ] 访问 `/storage`，确认页面显示 “Local HTTP POC” 警告。
- [ ] 连接有测试 CFX 的钱包，并确认当前网络是 Conflux eSpace 测试网。
- [ ] 选择小型非敏感测试文件。
- [ ] 记录页面计算出的 Merkle Root 和 Submission identity。
- [ ] 确认存储费用是 `0 CFX`，并单独检查钱包显示的网络 Gas。
- [ ] 点击“提交一次并上传”，只批准一次 `submit` 交易。
- [ ] 记录 TxHash：`______________________________`。
- [ ] 记录 TxSeq：`______________________________`。
- [ ] 等待页面显示节点已同步并完成所有分段上传。
- [ ] 确认页面完成回读，且显示 Merkle Root 校验通过。
- [ ] 保存校验后的文件，并与原文件进行字节比较。

## 刷新恢复测试

- [ ] 在交易回执已取得、上传尚未完成时刷新页面。
- [ ] 页面应提示已恢复一条提交后的会话，并要求重新选择原文件。
- [ ] 重新选择相同文件；按钮应显示“继续直传”。
- [ ] 继续后钱包不得再次弹出 `submit` 交易。
- [ ] 选择不同文件时，页面必须因 Root 不匹配而阻止继续。

## 下载入口测试

- [ ] 断开钱包后，使用刚记录的 TxSeq 下载并校验文件。
- [ ] 使用同一文件的 Merkle Root 再测试一次下载。
- [ ] 输入无效 TxSeq/Root，确认错误获得焦点且输入控件标记为无效。
- [ ] 在 Root 校验完成前，不得出现本地保存链接。

## 失败状态

- [ ] 两个节点都不可用时，页面不得尝试提交或上传。
- [ ] 节点 FileInfo 的 Root、TxSeq 或逻辑大小不一致时，流程必须停止。
- [ ] 钱包拒绝交易时，应允许重试，但不得在没有再次点击的情况下自动请求交易。
- [ ] 超过 100 MiB 或空文件必须在交易前被拒绝。
